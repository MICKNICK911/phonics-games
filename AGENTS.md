# Project instructions

- Design learning activities for young learners, especially KG through Grade 2.
- Prefer clear, playful, interactive experiences with immediate feedback.
- Support mobile screens and touch input; include keyboard input when useful.
- Keep changes consistent with the existing activity's layout and standalone HTML, CSS, and JavaScript structure.
- Reuse the project's word lists and lesson data when relevant.
- Use Ghanaian examples where they fit the learning content.
